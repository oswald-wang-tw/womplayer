# Womplayer branding

Womplayer is named after the wombat. The headphone-wearing mascot represents a
friendly companion for listening, sentence repetition, and shadowing practice.

- Display name: **Womplayer**
- Repository and primary command: `womplayer`
- Tagline: **Your listening and shadowing companion.**
- Logo: [`womplayer-logo.png`](../src/podcast_practice/assets/womplayer-logo.png),
  a transparent PNG shared by the README, library, player, and favicon.
- The HTML renderer embeds the logo as a data URI so exported pages remain offline.
- The legacy `podcast-practice` command and `podcast_practice` Python namespace
  remain available. The original browser storage keys are intentionally retained
  to preserve playback progress.

## Logo source

Generated with the built-in ImageGen tool on 2026-11-15. No fallback CLI was used.
The original generated PNG is included without visual edits.

### Generation prompt

```text
Use case: logo-brand
Asset type: production mascot logomark for Womplayer, an offline English listening and shadowing practice player. Used in a GitHub README and as a small app header icon.
Primary request: one original, charming wombat wearing over-ear headphones, a calm attentive listening companion. A recognizably wombat face with broad rounded head, short rounded ears, wide blunt dark nose, small friendly eyes and a subtle smile. Head and a little shoulder only, front view.
Style/medium: polished minimal flat vector-like illustration, confident clean shapes, rounded silhouette, restrained details, crisp edges, professional open-source app identity. Not photorealistic, not 3D.
Composition/framing: one centered mark on a square canvas, fills about 85 percent of canvas, generous clean padding, strong silhouette legible at 40 pixels.
Color palette: warm taupe wombat, deep forest/teal green headphones matching #27645d, dark charcoal #242a2c details, small warm peach inner ears. Compatible with warm off-white #fbf7f0 UI.
Scene/backdrop: genuinely transparent background with alpha, no background rectangle or badge, no cast shadow.
Text: none. Do not draw any letters, words, slogans or watermark.
Constraints: wombat rather than koala or bear; headphones should clearly frame the short ears, no microphone boom. Single mascot mark only; no mockup, no sheet of variants, no surrounding decoration.
```
